# Color Channel Splitter

Analiza y descompone imágenes en canales de color **RGB**, **CMYK**, **HSV** y monocromáticos (escala de grises, luminancia Rec.709 y sepia).

**Todo el procesamiento se realiza localmente en tu navegador.** Ninguna imagen se sube a ningún servidor.

## Uso online

👉 **[Abrir Color Channel Splitter](https://pollococo-star.github.io/color-channel-splitter/)**

## Características

- Subida por clic o arrastrar y soltar
- Canales RGB (rojo, verde, azul)
- Canales CMYK (planchas de impresión)
- Canales HSV (tono, saturación, valor)
- Modos monocromáticos: escala de grises, luminancia y sepia
- Inspección de píxeles (coordenadas + RGB + HEX)
- Vista ampliada y descarga individual o de todos los canales
- Interfaz oscura con acentos dorados, responsive

## Créditos

Diseño y desarrollo propio. Compatible con el ecosistema de herramientas locales de [image2cpp](https://github.com/pollococo-star/image2cpp).
